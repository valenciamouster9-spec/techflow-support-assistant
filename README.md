# TechFlow Support Assistant

A rule-based customer support and sales chatbot built with Node.js and Express, designed to demonstrate customer support, sales qualification, and technical troubleshooting logic in a working web application.

## Features
- Answers common customer questions (pricing, refunds, login issues, integrations)
- Qualifies sales leads by asking about team size and use case
- Escalates to a human agent when needed
- Simple, responsive chat interface built with HTML/CSS/JavaScript

## Tech Stack
- *Backend:* Node.js, Express
- *Frontend:* HTML, CSS, JavaScript (vanilla)

## How to Run Locally
1. Clone this repository
2. Run npm install
3. Run node index.js
4. Open http://localhost:3000 in your browser

## About This Project
This project was built to demonstrate the kind of thinking and workflows used in technical support and customer success roles — including intent detection, structured knowledge bases, and clear escalation paths — combined with basic full-stack web development skills.
